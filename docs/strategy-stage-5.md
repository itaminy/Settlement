Красные выиграли на карте 100×100 с четырьмя активными бандитами.
Синих игроков не было. Матч закончился через 900,67 с со счётом 105 : 0.

## TCP-сценарий с активным противником

Сценарий подготавливает позднюю стадию матча с оценкой 90 : 15,
затем обе стороны действуют через TCP. Синий игрок наносит 10 HP урона дому.
Красный бот одним ударом добивает синюю башню, снижает счёт противника до 80,
ремонтирует дом с 190 до 200 HP и возобновляет добычу дерева.
Синий игрок строит лесопилку и выигрывает 100 : 15 через 9,44 секунды после
первого удара. После команды перезапуска счёт обнуляется, сервер создаёт
четырёх бандитов, а бот с прежними учётными данными начинает добычу в новом матче.

```powershell
clojure -M scripts/check_strategy_tcp.clj
clojure -M scripts/check_world_v3.clj smoke
clojure -M -m settlement.world-test all
swipl -q -s prolog/settlement_dcg_test.pl -s prolog/settlement_knowledge_test.pl -s prolog/settlement_pathfinding_test.pl -s prolog/settlement_bot_test.pl -s prolog/settlement_strategy_test.pl -g 'run_tests,halt'
git diff --check
```
