# Prolog-бот Settlement

Проверено на SWI-Prolog 11.0.0. Добавьте каталог с `swipl.exe` в `PATH`.
Команды выполняются из корня репозитория.

## Запуск в Windows

В первом окне PowerShell запустите сервер. По умолчанию клиент подключается к
`127.0.0.1:5000`.

~~~powershell
clojure -M:run
~~~

Во втором окне запустите быструю проверку подключения:

~~~powershell
swipl -q -s prolog/smoke_test.pl -- 9001
~~~

Сценарий регистрирует игрока, загружает снимок в базу знаний, закрывает сокет
и повторяет проверку со входом по выданному токену. Токен хранится в памяти
процесса.

Для автономной игры укажите свободный положительный ID игрока, лимит
игровых команд и лимит времени в секундах:

~~~powershell
swipl -q -s prolog/settlement_bot.pl -- 9002 8000 1200
~~~

Интервалы бота задаются переменными окружения. Первые три переменные
читают сервер и бот. Задавайте одинаковые значения в обоих процессах.
Интервал игровых действий можно увеличить от 700 мс.

| Переменная | По умолчанию, мс | Интервал |
|---|---:|---|
| `SETTLEMENT_BOT_MOVE_MS` | 350 | Между шагами |
| `SETTLEMENT_BOT_ACTION_MS` | 700 | Между игровыми действиями |
| `SETTLEMENT_BOT_BUILD_MS` | 2000 | После строительства |
| `SETTLEMENT_BOT_DECISION_MS` | 1000 | Между стратегическими решениями |

Каждый запуск командной строки регистрирует нового игрока. В текущем экземпляре
сервера выбирайте ещё не зарегистрированный ID. Для нового матча запустите
отдельный экземпляр сервера. Бот выводит подтверждённые действия, счёт из
снимков и итог вида `stopped(victory,952)`. Лимит команд включает попытки
игровых действий, в том числе heartbeat добычи. Получение снимков,
ожидание и завершение соединения выполняются вне счётчика.
`Ctrl+C` запрашивает остановку с отменой активной добычи.

## Отдельный сервер для тестового матча

В первом окне запустите новый сервер на другом порту:

~~~powershell
clojure -M -e "(require 'settlement.server) (settlement.server/start-server 5521)"
~~~

Во втором окне задайте порт для клиента, затем запустите бота:

~~~powershell
$env:SETTLEMENT_PORT = '5521'
swipl -q -s prolog/settlement_bot.pl -- 9001 8000 1200
~~~

Переменная действует также для `smoke_test.pl`. Локальные логи и результаты
матчей можно сохранять в `.settlement/`, который игнорируется Git.

## Автоматические тесты

Следующая команда запускает все пять наборов Prolog-тестов. Для них сервер
не требуется. TCP-проверка запускается отдельно через `smoke_test.pl`.

~~~powershell
swipl -q -s prolog/settlement_dcg_test.pl -s prolog/settlement_knowledge_test.pl -s prolog/settlement_pathfinding_test.pl -s prolog/settlement_bot_test.pl -s prolog/settlement_strategy_test.pl -g 'run_tests,halt'
~~~

## Модули

- `settlement_client.pl` — авторизация и TCP-сеансы. `fetch_snapshot/4`
  возвращает строку снимка для разбора через `parse_frame/2`.
- `settlement_dcg.pl` — разбор ответов и push-событий текстового протокола.
- `settlement_knowledge.pl` — снимки, динамические факты и состояние синхронизации.
- `settlement_pathfinding.pl` — маршруты A* и проверка доступности при строительстве.
- `settlement_strategy.pl` — оценка полезности развития поселения, ремонта,
  рейдов, перехвата бандитов и отступления. Учитывает длину маршрута A* и
  близость бандитов к клеткам маршрута.
- `settlement_strategy_config.pl` — веса полезности, пороги угрозы и сроки
  повторной проверки отклонённых целей.
- `settlement_bot.pl` — автономный цикл. Обычные команды идут через текстовый
  протокол, изготовление инструмента использует отдельное EDN-соединение.

Форматы сообщений описаны в [документации протокола](../docs/text-protocol.md).

Журнал стратегии выводится при смене цели или причины выбора. Например,
`deny_enemy_victory` означает рейд из-за высокого счёта противника,
`defend_settlement` — перехват по наблюдаемой позиции и направлению бандита,
`evade_bandits` — отход при угрозе. `no_route` означает, что A* не нашёл
маршрут в текущем снимке. Переход на новую цель не сбрасывает серверные интервалы.

Автономный матч и TCP-сценарий с активным синим игроком запускаются отдельно:

~~~powershell
clojure -M scripts/check_world_v3.clj match
clojure -M scripts/check_strategy_tcp.clj
~~~
